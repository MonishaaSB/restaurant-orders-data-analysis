#  Restaurant Orders Data Analysis

## Project Overview
This is a beginner-friendly **Data Analysis mini project** that analyzes restaurant order data using Python.

The project focuses on understanding **food ordering patterns, sales performance, popular food categories, payment methods, and order timings** through data analysis and visualization.

The main goal is to convert raw restaurant order data into meaningful and easy-to-understand insights.
## Project Objective
The objectives of this project are to:
* Understand and clean restaurant order data
* Analyze customer ordering patterns
* Identify the most popular food items and categories
* Analyze sales performance
* Understand commonly used payment methods
* Identify the busiest ordering time
* Create meaningful data visualizations
* Generate insights from the analyzed data
## Dataset
The dataset contains **500 restaurant orders with 8 original columns**.
### Dataset Columns
| Column           | Description                        |
| ---------------- | ---------------------------------- |
| `Order.ID`       | Unique ID of the order             |
| `Customer.Name`  | Name of the customer               |
| `Food.Item`      | Food item ordered                  |
| `Category`       | Category of the food item          |
| `Quantity`       | Quantity ordered                   |
| `Price`          | Price of the food item             |
| `Payment.Method` | Payment method used                |
| `Order.Time`     | Time at which the order was placed |
### Dataset Source
The dataset was obtained from a public Kaggle dataset.

## Sales Calculation
A new column called `Total_Sales` was created using:

Total_Sales = Quantity × Price

This helps analyze the sales generated by different food items and categories.
## Order Time Analysis
The `Order.Time` column was converted into a datetime format.
The hour was extracted from the order time to identify the busiest ordering period.
df["Order_Hour"] = df["Order.Time"].dt.hour
